# 掲載情報と提供資料

| 資料 | 用途 |
|---|---|
| [掲載内容.md](掲載内容.md) | 店舗情報・サービスの掲載根拠 |
| [source_materials/photos](source_materials/photos) | 提供された写真資料 |
| [source_materials/videos](source_materials/videos) | 提供された映像資料 |

サイトの掲載文章・サービス・連絡先は [src/content.ts](../01_website/src/content.ts)で編集します。情報を更新するときは、提供資料との整合を確認します。

Webページで使用する画像は [public/media/images](../01_website/public/media/images)に配置します。参考資料の原本はこのフォルダで保持し、サイトでの見せ方はコンポーネントとスタイルで調整します。

実装と確認の手順は [WebサイトのREADME](../01_website/README.md)、映像の生成は [制作ガイド](../02_render/RENDER_GUIDE.md)を参照してください。
