# CAR PRODUCE ONE — Webサイト

React + Viteの静的サイトです。ChatGPT Sitesには依存しません。

## 起動

ルートの `../OPEN_PREVIEW.cmd` を開くか、このフォルダで以下を実行します。

```text
npm ci
npm run dev
```

ローカルURLは http://127.0.0.1:5173/ です。
`npm run build` で `dist` を生成、`npm run preview` でビルド済みサイトを確認できます。公開先は第7段階で設定します。

## 第5段階で完成した範囲

6サービスを説明付き一覧にし、各項目から相談セクションへ移動できるようにしました。
工具と雑誌の3Dイメージを使った店舗紹介、住所・地図リンク、電話・LINE・QRコード、フッターナビゲーションを実装しました。
`#services`、`#about`、`#access`、`#contact` を付けたURLで本文へ直接移動できます。メニューからの移動後は対象セクションへフォーカスし、スマートフォンのメニューはEscでも閉じられます。

モニター内と本文冒頭は同じMainHeroを使用します。接続完了前は本文のレイアウトを保持したままvisibilityをhiddenにし、画面下から本文が先に見えることを防いでいます。本文のスタイルを変更するときはこの共有ヒーローへ影響させないでください。現在の動画は確認用画質です。最終30fpsへの差し替えと最適化は第6段階で扱います。

## 交差点からの接続

最初の走行は10秒のループです。スクロール開始時の再生位置を記録し、次の共通地点まで走ってから、16秒の「減速→90度右折→直進」の映像へ接続します。
建物を含む街区は固定し、車と車載カメラを同じ経路上で動かしています。接続のための建物マスクや、車内だけを固定画像で覆う処理はありません。

- `src/JunctionTransition.tsx`: 右折映像のスクロール制御。
- `src/junction-transition.ts`: 開始位置から共通地点への時間対応。
- `public/media/junction/{desktop,mobile}/drive.mp4`: 共通地点へ続く走行ループ。
- `public/media/junction/{desktop,mobile}/turn.mp4`: 進入・右折・合流。

初期区間は全スクロール範囲の先頭18%です。その後の到着映像への時間変換も、接続点で進む速さが連続するよう調整しています。工具・雑誌・モニターの停止位置は維持しています。
現在は動き確認用で、走行は8fps、右折は12fpsです。Blenderの元シーンは30fpsです。最終動画へ差し替えるときは `DRIVE_FPS` と `TURN_FPS` も合わせて変更します。
右折映像の最後の1フレームは、同じカメラ位置にある既存の到着動画の先頭画像を使用し、確認用動画間の画質差を抑えています。3D原本にはこの画像処理を含みません。

`npm test` は21件。固定された街区、90度の旋回、車載カメラの追従、建物との間隔、ループと接続点の画像差を検証済みです。
検証記録は `../02_render/reports/junction-scene-validation.json` と `junction-media-validation.json`。動画の照合情報は `junction-media-manifest.json` に保存しています。
以前の方式のコード・動画・検証記録は `../90_archive/connection_slide` に保管しています。
