# CAR PRODUCE ONE — Webサイト

React + Viteの静的サイトです。ChatGPT Sitesには依存しません。

## 起動

ルートの `../OPEN_PREVIEW.cmd` を開くか、このフォルダで以下を実行します。

```text
npm ci
npm run dev
```

ローカルURLは http://127.0.0.1:5173/ です。
`npm run build` で `dist` を生成、`npm run preview` でビルド済みサイトを確認できます。公開先は第7段階で設定します。

## 第5段階で完成した範囲

6サービスを説明付き一覧にし、各項目から相談セクションへ移動できるようにしました。
工具と雑誌の3Dイメージを使った店舗紹介、住所・地図リンク、電話・LINE・QRコード、フッターナビゲーションを実装しました。
`#services`、`#about`、`#access`、`#contact` を付けたURLで本文へ直接移動できます。メニューからの移動後は対象セクションへフォーカスし、スマートフォンのメニューはEscでも閉じられます。

モニター内と本文冒頭は同じMainHeroを使用します。接続完了前は本文のレイアウトを保持したままvisibilityをhiddenにし、画面下から本文が先に見えることを防いでいます。本文のスタイルを変更するときはこの共有ヒーローへ影響させないでください。現在の動画は確認用画質です。最終30fpsへの差し替えと最適化は第6段階で扱います。

## 交差点からの接続

サイトの最初の走行は、新しい街並みを使った20秒・160mのループです。スクロール開始時の再生位置から共通地点まで走り、16秒の「減速→90度右折→直進」を経て既存の到着映像へ接続します。街区は固定し、車と車載カメラを同じ経路で動かしています。

- `src/JunctionTransition.tsx`: 右折映像のスクロール制御。
- `src/junction-transition.ts`: 20秒・30fpsの時間対応と動画の版番号。
- `public/media/junction/{desktop,mobile}/drive.mp4`: 600フレーム・30fpsの走行ループ。
- `public/media/junction/{desktop,mobile}/turn.mp4`: 481フレーム・30fpsの右折と合流（16秒＋終端1フレーム）。

初期区間は全スクロール範囲の先頭18%です。到着映像への接続点で進む速さが連続するよう時間を変換しています。工具・雑誌・モニターの停止位置は維持しています。
冒頭へ戻る際はスクロール用のシークを解除し、動画全体の自動周回へ戻します。動画と冒頭画像のURLに`JUNCTION_MEDIA_VERSION`を付け、差し替え前のキャッシュが残ることを防ぎます。

現在は横640×360・縦360×640、Cycles 16 samplesのテスト品質です。到着後の既存動画は8fps／24fpsを使用しています。右折の最後の1フレームには、同じカメラ位置の到着動画の先頭画像を使用し、確認用動画間の画質差を抑えています。この画像処理は3D原本には含みません。

最新MASTERには、カフェ・ホテル・オフィス・ガレージ・閉店中の店舗・奥まったロビーの6種類の1階、大小24面の追加広告、8種類の新しい広告画像、背後の11棟、街路樹8本、駐車区画の車1台、バス停と街路設備を配置しています。車は道路中心から2.6m左の車線を走ります。
街区と濡れた路面の模様を160m周期にそろえています。検証では始点・終点だけでなく、圧縮後の最終フレーム→先頭フレームの画像差を通常の隣接フレームと比較します。

`npm test`は23件。メディアの照合情報は`../02_render/reports/junction-media-manifest.json`、接続と周回の検証結果は`junction-media-validation.json`、モデルの検証結果は`junction-scene-validation.json`です。ブラウザーでの操作記録は`junction-site-verification.json`に保存しています。
以前の方式のコード・動画・検証記録は`../90_archive/connection_slide`に保管しています。最終画質の全編描画はまだ実行していません。
