# CAR PRODUCE ONE — Webサイト

React + Viteの静的サイトです。ChatGPT Sitesには依存しません。

## 起動

ルートの `../OPEN_PREVIEW.cmd` を開くか、このフォルダで以下を実行します。

```text
npm ci
npm run dev
```

ローカルURLは http://127.0.0.1:5173/ です。
`npm run build` で `dist` を生成、`npm run preview` でビルド済みサイトを確認できます。公開先は第7段階で設定します。

## 第5段階で完成した範囲

6サービスを説明付き一覧にし、各項目から相談セクションへ移動できるようにしました。
工具と雑誌の3Dイメージを使った店舗紹介、住所・地図リンク、電話・LINE・QRコード、フッターナビゲーションを実装しました。
`#services`、`#about`、`#access`、`#contact` を付けたURLで本文へ直接移動できます。メニューからの移動後は対象セクションへフォーカスし、スマートフォンのメニューはEscでも閉じられます。

モニター内と本文冒頭は同じMainHeroを使用します。接続完了前は本文のレイアウトを保持したままvisibilityをhiddenにし、画面下から本文が先に見えることを防いでいます。本文のスタイルを変更するときはこの共有ヒーローへ影響させないでください。現在の動画は確認用画質です。最終30fpsへの差し替えと最適化は第6段階で扱います。

## B＋C：曲がり角の建物による接続

このブランチでは、最初のぼかし接続を建物の遮蔽に置き換えています。
走行ループ → 建物が窓外を覆う → 32度の旋回を含む通りの見え方 → 既存の到着映像、という構成です。
車内は固定の前景画像を重ねます。スクロール開始時の走行ループの位置を記録し、接続の前半と逆送りで同じ位置を再現します。

- `src/CornerTransition.tsx`: 接続動画の表示と、実際の提示フレームに合わせた建物の輪郭マスク。
- `src/corner-transition.ts`: 接続区間、フレーム番号、画面比率ごとの座標変換。
- `src/corner-tracking.json`: Blenderから出力した97フレームの建物輪郭。
- `public/media/corner/{desktop,mobile}/corner.mp4`: 30fps・全フレーム独立の接続動画。

接続は全スクロール範囲の先頭6.5%です。既存の工具・雑誌・モニターの停止位置は維持しています。
建物が全画面を覆う48フレーム目で窓外を切り替えます。提示フレーム通知がないブラウザーでは、次のシークを発行する前に完了フレームを取得します。
確認用動画の最後3フレームは、既存の低解像度の到着動画の先頭画像へ画質を合わせています。3D原本はこの処理を含まず、同じカメラ位置へ連続して到達します。

検証は `npm test` の20件と、`../02_render/reports/corner-validation.json`、`corner-scene-validation.json`。
横・縦の実ページで、前進・停止・逆送り・到着映像への接続を確認しています。新しい公開先へのデプロイは行っていません。
