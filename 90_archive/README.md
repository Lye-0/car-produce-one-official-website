# 保管用フォルダ

ここは過去の制作履歴です。現在の作業はルートの01_websiteと02_renderを使ってください。

- legacy_project: 初期のプロジェクト。v16（整理前の未コミット編集を含む）、v17、以前の資料・ツール。
- sites_project: 段階4までの旧Sitesサイト一式。旧Git履歴と依存パッケージも保管。現在のサイトは01_website。
- session_outputs: 過去の納品・確認用出力。CPO_stage4/CPO_v18_site_assets.blendがMASTERの元ファイル。
- session_work: 中間フレーム、ログ、生成・検証用作業ファイル。
- relocation-map.json: 整理前と整理後のパス対応。
- 整理前の記録.json: 整理前の主要ファイル情報。

旧スクリプトや文書には移動前の絶対パスが含まれます。記録として保存しているため、再利用時はパスの見直しが必要です。
元のv16ファイルはSHA256を照合し、内容が変わっていないことを確認しました。
