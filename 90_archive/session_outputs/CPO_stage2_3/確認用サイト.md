# スクロール連動版（改訂2）

確認用サイト（本人限定）：https://cpo-journey-prototype.lye-0.chatgpt.site

- スクロール位置に合わせて、カメラの映像時刻を直接更新します。
- 途中で止めるとカメラも止まり、上へ戻すと同じ経路を逆に戻ります。
- 工具・雑誌・モニターの読む区間には、静止カメラの背景ループを用意しています。
- モニターへの接近、HTMLの拡大・表示、本編への切り替えはスクロール量で決まります。
- 本編の先頭から上へ戻すと、モニターへの移行も逆方向にたどれます。
- 場面ボタンはページのスクロール位置を移動します。

検証：途中移動・停止・逆戻り・読み物区間・連続シーク・読み込み前の操作・端点の7テストが成功。型チェックとビルドも成功。ブラウザー上の操作・視覚検証は未実施です。

元映像は640×360・8fpsの確認用素材です。今回、720フレームすべてを独立して読み出せる形式に変換し、背景ループ3本を追加しました。高解像度化、縦画面専用の構図、街の窓内だけの継ぎ目処理、モニター四隅への厳密な重ね合わせは別途調整する項目です。
