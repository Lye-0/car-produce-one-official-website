# CAR PRODUCE ONE — サイト専用素材（段階4）

このフォルダーは、横画面・縦画面の構図、固定カメラの背景ループ、街から到着への接続、モニターからHTMLへの移行を準備するための素材です。

## 制作データ

- `CPO_v18_site_assets.blend`：v17を基にしたサイト専用データ。元のv17と既存のv16ファイルは変更していません。
- `asset-setup.json`：カメラと素材の構成。
- `screen-tracking.json`：フレーム2430〜2700のモニター四隅。横画面と縦画面の2種類。
- `scene-validation.json`：固定カメラと街ループの接続位置の検証。
- `media-manifest.json`：完成した動画の寸法、フレーム数、容量、ループの継ぎ目の検証結果。
- `stills/`：構図確認用の静止画と、車内だけを取り出した透過素材。

## サイトでの役割

| 素材 | 内容 |
| --- | --- |
| 街のループ | 48秒の街を繰り返し、任意のタイミングで到着映像へ進む |
| 車内の透過素材 | 車内を安定させ、切り替えを窓の外に限定する |
| 移動区間の確認映像 | 横画面960×540・縦画面540×960、8fps・81秒の組み立て確認用 |
| 工具・雑誌・モニターのループ | 横画面1280×720・縦画面720×1280、24fps・各6秒。カメラを固定し、光だけを周期的に動かす |
| モニターへの接近 | 同寸法・24fps。PC前の固定位置から接近する9秒間を省略せず収録 |
| 四隅の追跡データ | 画面に実際のHTMLを重ね、文字の修正をそのまま反映する |

モニター内の文字は映像に焼き込んでいません。映像素材だけを見ると画面は暗い状態ですが、サイト上では本編と同じHTMLが表示されます。

## 操作との関係

スクロール位置がカメラの位置を決めます。背景ループの経過時間がカメラを進めることはありません。

読む位置は、工具が元の時間軸の34.2秒、雑誌が56.7秒、PCが81秒です。PC前の固定を終えてから、81〜90秒の接近経路を通ります。モニター枠が画面外に出た後に、本編の画面サイズへ合わせます。

縦画面は専用の画角とレンズ推移を使用します。工具・雑誌を上側へ置き、下側に文章を表示できる構図です。

## 次の段階

段階5では、本編の情報・レイアウト・導線を仕上げます。段階6では、確定したカメラと接続を用いて、移動区間全体の最終画質・フレーム数・容量を整えます。現在の全区間動画は組み立て確認用です。

## 書き出した動画

動画は `videos/desktop/` と `videos/mobile/` に分けて保存しています。

- `city.mp4`：48秒の街ループ。
- `route.mp4`：街からPC手前までの81秒の確認映像。
- `tools-idle.mp4`、`magazines-idle.mp4`、`monitor-idle.mp4`：各6秒の固定カメラループ。
- `portal.mp4`：PC前から画面へ接近する区間。

サイトはこれらをスクロール位置に応じて使い分けます。動画単体の再生時間が、そのままサイトでの待ち時間になることはありません。
## 検証

- 12本の動画をデコードし、形式・寸法・フレーム数を確認。
- カメラの停止位置と、街ループのカメラ位置・向きを確認。
- 6本の読書用ループについて、圧縮前と圧縮後の継ぎ目を測定。
- 街ループの始点・終点、および4つの切り替え時点で車内が固定されることを確認。
- スクロール停止・逆戻り・24fpsの位置指定・四隅への投影など15件のテストが成功。
- サイトのビルドとローカル応答を確認。ブラウザー上の実操作・視覚検証は未実施。
