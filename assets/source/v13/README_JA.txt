CAR PRODUCE ONE — v13 / 連続カメラ・スクロール体験の実装版
=============================================================

このデータは、v12の実際の3Dモデルに車・街・カメラ・建具のアニメーションを追加したものです。
静止画を3Dモデルの代わりにしたものではありません。

1. 最初に見るファイル
-------------------------------------------------------------
CAR_PRODUCE_ONE_ANIMATED_v13.glb
  店舗の内装と外装、展示車2台、導入用の車、夜の街、カメラ、アニメーション。
  カメラ名: CPO_CINEMATIC_CAMERA
  メイン: CPO_MASTER_90s / 0〜90秒
  車窓ループ: CPO_IDLE_CITY_LOOP（独立した任意のループ）
  位置・回転は30fps相当、0〜2700フレームに対応。

previews/CPO_full_journey_review.mp4
  GLBのアニメーションを実際に評価して描画した90秒の動線確認動画。
  800×500 / 8fps / 音声なし。計算量を抑えた確認用で、最終画質・最終フレームレートではありません。
  全景のループと画面からHTMLへの接続はWebプレイヤー側で動きます。

2. Windowsでスクロール確認
-------------------------------------------------------------
ZIPをすべて展開して、START_PREVIEW.cmd をダブルクリックしてください。
ブラウザーで http://127.0.0.1:8765/web/ 付近のアドレスが開きます。
ポートが使われている場合は別の番号を自動選択します。

必要なもの: Python 3 と、WebGL2を利用できるブラウザー。
Pythonの追加パッケージやインターネット接続は不要です。
サーバーはローカルPCだけで待ち受けます。終了は端末で Ctrl+C。
手動起動: python START_PREVIEW.py

index.htmlを単体でダブルクリックする方法は、GLBの読み込み制限に当たる場合があります。
START_PREVIEW.cmd、または同等のローカルHTTPサーバーを使ってください。

操作:
・スクロール: 最初から最後までの時間軸を進める/戻す
・再生: 90秒の通常再生
・スライダー: 任意位置へ移動
・確認地点: 工具台、雑誌、PCなどへ移動
・揺れ: 停止中の微小な揺れを切り替え
・俯瞰/自由視点: 全体を確認。ドラッグで回転、ホイールで距離変更
・リセット: 最初の車内ループへ戻る

初期の街のループは実時間、本編はスクロールの時間軸です。
ループから本編へ移る際は、街のループ位相を保って位置の飛びを避けます。
動きを減らす設定がある端末では、初期ループと微小揺れを自動で抑制します。

3. Blenderで再生
-------------------------------------------------------------
旧モデルを重ねてインポートしないでください。今回のファイルは統合版です。

推奨:
1) BlenderのScripting画面で、展開した OPEN_IN_BLENDER.py を開く。
2) 実行する。同じ場所のGLBを読み込み、新しいシーンを作成します。
3) CPO_CINEMATIC_CAMERA が選択された状態でカメラビューへ。
4) フレーム 0〜2700、30fps で再生する。
5) 作業を続ける際は「名前を付けて保存」で .blend として保存する。

スクリプトは既存のシーンを削除せず、新しいシーンを追加します。
保存も自動では行いません。SAVE_BLEND=Trueを明示的に設定した場合だけ、既存ファイルを
上書きしない別名の .blend を保存します。
スクリプトの実行場所が分からない場合は、先頭のMODEL_PATHにGLBの完全なパスを設定してください。

手動でも「ファイル → インポート → glTF 2.0」でGLBを読み込めます。
カメラは CPO_CINEMATIC_CAMERA、主アニメーションは CPO_MASTER_90s です。
90秒の主アニメーションと車窓ループを同時に重ねず、主アニメーションを選んでください。
補助スクリプトは主アニメーションの撮影時に街ループを無効化します。

.BlendファイルはこのZIPには含めていません。
この制作環境ではBlender本体を実行できないため、Blenderインポート・スクリプト実行・最終レンダーは未検証です。

4. 今回実装した流れ
-------------------------------------------------------------
夜の車内 → 到着 → 左助手席側のドアを開けて降車 → 店舗へ向かう → ガラス建具を開いて入店
→ 工具台で停止 → 横移動してガラス机へ → 雑誌に注目して停止 → デスク奥を回り込む
→ 目的のPCへ向きを合わせて接近 → Web上でシックな本編先頭のサンプルへ接続

工具台の固定: 34.2〜43.2秒（進行度38〜48%）
雑誌の固定: 56.7〜67.5秒（進行度63〜75%）
カメラの主位置・向きは固定。微小揺れはWeb側で別に加算します。
PCの手前までは人が通れるルートを基準にし、その後は画面に近づく映画的な視点移動です。
液晶面の裏や、机の中へカメラを突き抜けさせる方式ではありません。

GLBにHTMLやスクロール制御が入っているわけではありません。
最後のHTML接続、スクロール進行度、実時間のループ制御は web/ の実装です。
本編は接続確認用の先頭サンプルで、正式な会社情報・予約・問い合わせは未実装です。

5. 既存部分の変更
-------------------------------------------------------------
建物の内外装、壁、L字デスク、工具台、プリンター、書類棚と時計、ガラス机本体は維持。
通路を開けるため、合意済みの小家具だけを移動しています。
  F05.RollingStool.0: X −0.605m
  F05.RollingStool.1: X −0.605m
  05f_Rear_Side_Unit_And_Basket: X −0.15m
  07d_End_Utility_Cabinet: X +1.254m / Y −1.692m
また、入店に使う前面のガラス2枚に開閉アニメーションを設定しました。
目的のPCの画面材質は、Webと色・構図をつなぐための仮表示へ差し替えています。

座標: X=図の右、+Y=店舗の奥、+Z=上。道路は−Y側。
GLBには従来のY-up変換ルートを残しています。

6. 車両と見た目の品質について
-------------------------------------------------------------
展示車は、参考写真と外寸を基に独自に作成した近似モデルです。
左: 少し暗めの青のクーペ（プレリュード参考）
右: 黒いSUV（ヴェゼル参考）
両方とも入口の−Y方向を向きます。

メーカーのCADや市販の高精細車両モデルではありません。
現段階では、ボディの曲面、窓・ライト形状、車内などに実車との差があります。
今回は配置・動線・全編のアニメーションが確認できる制作モデルで、車の接写用の
最終品質を満たしたという意味ではありません。今後、同じ車両グループ内で精細化・差し替えできます。

夜の街は、この作品用に作った仮想の背景です。実際の周辺地域の再現ではありません。
Web描画は動線確認用に照明・反射・透過を簡略化しています。最終映像はBlenderで照明を仕上げてください。

7. 検証の範囲
-------------------------------------------------------------
・GLBの再読み込み、アニメーションのキー値・時間・クォータニオン
・全テクスチャのサンプラー参照の明示（以前のBlender読込エラー対策）
・埋め込み画像のデコード
・元モデルのメッシュ形状の保持
・停止区間のカメラ位置と回転が一定であること
・歩行経路を30fpsで検査、主要な障害物との水平距離
・動く車体・建具とカメラ周辺のサンプル検査
・実GLBからの確認画像・動画の作成

歩行検査の仮想半径は0.275m。動線の最小中心距離は検証JSONを参照。
これは制作上の目安で、人体すべての運動の厳密な連続衝突証明、避難・バリアフリー等の法令判定ではありません。
WebGLがこの環境のブラウザーで無効のため、実ブラウザーでのGPU描画・表示速度の実測は未実施です。
シェーダーのネイティブコンパイル検証と、GPUを模した呼び出しによるUI・カメラ値のテストは区別して記録します。
source/DELIVERY_VALIDATION.json に結果を集約しています。
主データ/動線47項目、GPUを模したUI/姿勢検査27項目が通過し、GLSL 2本のネイティブコンパイルも成功しました。

8. 再生成と引き継ぎ
-------------------------------------------------------------
通常の閲覧ではsource/は不要です。
再生成には元のv12 GLB（別途必要）、Pythonと numpy/scipy/trimesh/shapely/Pillow等が必要です。
  python source/build_v13.py "元のv12.glb"
静止プレビュー再生成にはVTK、動画にはFFmpegも必要です。
  python source/render_v13.py
  python source/render_v13.py --video

カメラの経由点・時間配分は animation/timeline.json、サンプル値はcamera_samples.npz。
実際の生成元はsource/build_v13.pyです。JSONだけを編集してもGLBは更新されません。
発展させる際は、経由点/カーブを修正して再出力し、補間後の動線を必ず再検査してください。
