# v16 — 街との接続・カメラ方向・素材8項目の修正

## 変更内容

1. 店舗周辺の旧舗装、点字ブロック、側溝を非表示にし、街と共通の花崗岩歩道・縁石へ統一。主道路は連続した既存のアスファルト面を使用する。
2. 会社の建物・内装・展示車・照明をワールドY方向へ3.65m移動。正面を周囲の建物の基準線に合わせ、降車後から入店までのカメラを滑らかに新位置へ接続する。
3. 停止区間のカメラの位置・回転の揺れを最大1.8倍にし、区間の端で元の振幅へ戻す。Blenderのタイムラインを完全に一時停止した場合も動く仕組みではなく、アニメーション中の停止区間に適用する。
4. 1323フレーム付近で視線を左へ向けながら奥の壁側へ移動していた構成を変更。先に向きを変え、その後に雑誌テーブル側へ歩く動きにする。ワールド座標と取り込みモデルの座標系を変換し、全回転キーの符号を連続化する。
5. 都市ループの店舗複製を取り除き、通常の住宅棟に置き換える。店舗・社名・内装がループの依存先に含まれないことを検査する。
6. 天井の回り込み、窓からの補助光、オフィスの環境光等を13％減らす。車体と工具・雑誌に向けた局所照明を保持する。
7. 広告を8種類追加して計16種類とする。既存8種類も見える画面に割り当て、追加分は飲食・ファッション・音楽・旅行・家電・生活用品・科学の題材で変化を付ける。
8. 雑誌表紙を4種類追加して計8種類とする。テーブルの8冊を異なる誌名・表紙にし、追加4冊の厚みにも小さな差を付ける。

## 保存と検査

作業開始時のライブファイルは `work/checkpoints/before_v16.blend` にコピーして保全した。元のv15モデルは維持している。

編集ファイルは `assets/blender/CPO_v16_refined.blend`。メインシーンは `CPO_V16_MAIN`、都市ループは `CPO_V16_DRIVE_LOOP`。

カメラの確認区間は1260〜1515フレームを30fpsで描画する。数値検査は全2701フレームと、1200〜1520フレームの1/8フレーム刻みを対象とする。全小物に対する連続衝突の完全な保証ではない。

都市ループの始点・終点は周期を合わせている。到着シーンとはカメラ位置・向きを合わせているが、目的地の敷地に当たる建物が異なるため、接続確認動画には0.5秒のクロスディゾルブを用いる。到着との背景が完全に同一という検証ではない。

広告画像8点と雑誌画像4点は組み込みimagegenで個別に生成し、プロンプトを `docs/v16-art-provenance.json` に保存する。既存の8広告・4表紙は従来の素材を使用する。画像は作業用blendに内包する。

制作スクリプト `tools/refine_v16.py` は段階別に実行する。同じ段階を修正済みシーンへ無条件に再実行しない。
