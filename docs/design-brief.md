# 制作方針 — CAR PRODUCE ONE

## 現在のユーザー要望

母の車の整備会社「CAR PRODUCE ONE」の公式サイト。かっこよさ、オシャレさ、クリエイティブさを重視する。

背景に、夜の車内から店舗へ入ってPCへ向かうスクロールアニメーションを流す。手前には、濁った半透明（曇りガラスのような）のテキストブロックを重ねる。背景の移動が静かになるタイミングで文章などを切り替え、読む時間を作る。現時点では演出方針であり、配色・角丸・配置・切り替え方法の詳細は未確定。

黒基調、暗めの天井照明、木・金属・ガラスの質感を重視。昼間の写真は主に形状・位置の根拠。実店舗の特徴を残しながら小物の整理や照明の演出を行う。現案は変更可能で、良い案があれば検討する。

## 体験の流れ

1. 夜の近未来都市を走る車内。スクロール前は外景がループ。
2. 到着、降車、1階の店舗へ入る。
3. 工具台を向いて停止。テキストなどを見せる候補。
4. 左へ向きを変え、ガラス机とL字デスクの間へ進む。
5. ガラス内の雑誌に注目して停止。テキストなどを見せる候補。
6. デスクの奥を回り込み、L字デスク上のPCの正面へ。
7. PC画面が視界を満たし、落ち着いたサイト本編へつなぐ。

歩行可能な経路、自然な向き・高さを守る。最後の画面接近は映像的な移行であり、机や液晶を物理的に貫通させる要件ではない。

## 引き継ぐ空間の特徴

左側の展示車は暗めの青のプレリュードを参考にしたクーペ、右側は黒のヴェゼルを参考にしたSUV。いずれも入口方向を向く。現車両は近似モデル。

ガラス机は下が黒い木板、上がガラスで、その薄い隙間に雑誌がある。ガラス机側のモニターと、到達先であるL字デスクのPCは別物。

過去に修正された、木製扉左のX方向10cmの壁幅、書類棚と時計、プリンターのサイズ・位置・向き、三角形の工具台、工具収納の向き、道路側への1.5m延長、外装ロゴと看板の角の処理などには写真との照合履歴がある。意図なく元に戻さず、変更時は根拠を確認する。
